A short project guide

Small choices make a better experience.

This project is built around a few practical choices that make information easier to use.

Clarity

Use plain language, descriptive headings, and a clear next step so people can find what they need.

Accessibility

Make pages work with a keyboard, readable text, and form labels that explain what to enter.

Privacy

Ask only for information needed for the task, and keep the submitted details within the current browser session.

Simplicity

Keep each page focused: read the guide, write a summary, and review the result.
